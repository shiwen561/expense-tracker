导入账单预览

如何从微信 / 支付宝导出账单？ ▼
微信支付
  1. 打开微信 → 我 → 服务 → 钱包 → 账单
  2. 右上角 常见问题 → 下载账单 → 选择 用于个人对账
  3. 选择时间范围，填写邮箱，账单会发送到邮箱
  4. 下载邮件附件压缩包，解压得到 CSV 文件，在此导入
支付宝
  1. 打开支付宝 → 我的 → 账单
  2. 右上角 筛选 → 选择时间范围
  3. 点击 更多 → 开具交易流水证明
  4. 选择 用于个人对账，填写邮箱
  5. 下载邮件附件，解压得到 CSV/Excel 文件，在此导入

按上方的教程导出账单后，选择文件导入
